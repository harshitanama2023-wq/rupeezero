# RupeeZero

Zero-based budgeting for Indian households, with an FY 2026-27 old-vs-new tax regime planner.
Single HTML file — no build step, no backend. All data stays in the visitor's browser (localStorage).


## Disclaimer
Tax figures are estimates for salaried resident individuals (Budget 2026 slabs, GST 2.0 rates) and are not tax advice.

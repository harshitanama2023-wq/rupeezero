# RupeeZero

Zero-based budgeting for Indian households, with an FY 2026-27 old-vs-new tax regime planner.
Single HTML file — no build step, no backend. All data stays in the visitor's browser (localStorage).

## Run locally
Open `index.html` in any browser.

## Deploy on GitHub Pages
1. Push this folder to a GitHub repository (branch `main`).
2. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch `main`, folder `/ (root)` → Save.
3. Site appears at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Files
- `index.html` — the whole app (HTML, CSS, JS)
- `.nojekyll` — tells GitHub Pages to serve files as-is
- `LICENSE` — MIT

## Disclaimer
Tax figures are estimates for salaried resident individuals (Budget 2026 slabs, GST 2.0 rates) and are not tax advice.

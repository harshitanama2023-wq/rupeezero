            How the rules stay current

            Tax slabs and limits are not written into the app. They live in tax-rules.json, keyed by financial year. On every load the app fetches that file (and, if configured, a central copy on GitHub), keeps the newest version, and picks the ruleset for the current Indian financial year (1 April – 31 March). If a new year has started and its ruleset is not yet verified, the app says so and uses the latest verified one.

            No software can know a Budget's contents before they are announced, so "automatic" means: a maintainer edits one JSON file after the Budget speech (usually 1 February) and after the Finance Act passes; the repository's scheduled workflow opens a reminder issue on those dates; a validation script rejects malformed rules; every deployed copy updates itself on next open.
